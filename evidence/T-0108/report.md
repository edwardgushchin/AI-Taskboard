## Проверки и ограничения

- Node.js 24.14.0, npm 11.9.0, Electron 45.2.3, electron-builder 26.18.0, Windows x64.
- TypeScript: npm run check, exit 0.
- Основной набор: tests/documentation.test.ts, tests/codex-run.test.ts, tests/codex-chat-control.test.ts, tests/codex-chat-usage.test.ts: 10/10.
- Дополнительно tests/board-agent-hooks.test.ts и tests/reviewer-chat.test.ts: 2/2.
- npm run check:docs: локальные ссылки и фрагменты без ошибок. git diff --check: без ошибок.
- Первый build:cli до установки локальных зависимостей завершился MODULE_NOT_FOUND для жёсткого пути node_modules/postject; после npm ci повтор прошёл. Код сборки для этого не менялся.
- В тестах провайдера были ожидаемые предупреждения Could not save Codex token usage.; тесты завершились успешно. В сборке нет сертификата подписи, используется стандартный значок Electron. NSIS-установка, публикация, Linux и macOS не проверялись: изменено только включение файлов в пакет, установленный профиль пользователя не менялся.
- Живые сеансы модели не запускались. Передача инструкций проверена на App Server fixture; доступ к поставляемым файлам проверен настоящим Electron. Семантическая полнота документации проверена чтением исходников, не автоматическим доказательством всех возможностей приложения.
- Проверка путей inline code ограничена точными путями src, scripts и build. Условные примеры, выходные каталоги, произвольные shell-команды и внешние ссылки требуют ручной проверки. Это ограничение описано в руководстве разработки.

## Технические детали

После первого preview потребовалось объединение с main `9dfcf5d083368af4783cd22792e358a1d93d60e2`.
Сохранены локализация ответов, правила действий доски, проверки текущего reviewMode и полного доступа; к ним добавлено правило документации.
Старый design удалён, сведения о записи UTF-8 и запросе доступа описаны в новом справочнике агентов по codex-run.ts.
Для перенесённых исторических файлов сохранены исходные Git blobs; .gitattributes предотвращает их повторную нормализацию CRLF при сдаче.
Первичная побайтовая сверка с git show выявила нормализацию окончаний строк; после восстановления blobs содержание и байты сохранены.
После объединения TypeScript и все шесть перечисленных тестовых файлов повторены на `4307974`: 16/16.
Первый прогон после merge совпал с переустановкой node_modules и завершился ошибкой разрешения fflate; после завершения установки последовательный повтор прошёл.
Сверка 17 перенесённых исторических файлов с исходными Git blobs прошла побайтово.
Проверка diff после merge выполнена относительно target с core.whitespace=cr-at-eol, чтобы сохранённые CRLF исторических материалов не считались новыми пробелами.
После merge выполнена ещё одна сборка CLI и Windows --dir. Обновлённый общий Electron helper запускает проверки из временной папки; проверка пакета исправлена на путь к исходникам относительно import.meta.url вместо cwd.

Основные проверки:

```text
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm run check:docs
node --test tests/documentation.test.ts tests/codex-run.test.ts tests/codex-chat-control.test.ts tests/codex-chat-usage.test.ts
node --test tests/board-agent-hooks.test.ts tests/reviewer-chat.test.ts
npm run build:cli
git diff --check
```

Проверка поставки после сборки в отдельную временную папку:

```text
node node_modules/electron-builder/cli.js --dir --config.directories.output=TEMP_OUTPUT --publish never
node scripts/check-docs-package.mjs TEMP_OUTPUT/win-unpacked
```

В выполненном прогоне electronDist указывал на уже установленный Electron той же версии; для launcher использовался ELECTRON_OVERRIDE_DIST_PATH. Эти параметры относятся к проверке, а не к продукту или правилам агента.
После проверки удалены созданные dist, локальные node_modules, временная поставка и профили Electron. Исходный debug.log сохранён отдельно как артефакт карточки.
Контрольные суммы адаптированных файлов и отчёта находятся в checksums.sha256 рядом с этим отчётом.
