# T-0079: источник обновлений AI-Taskboard

Проверено 15 ноября 2026 года на Windows x64. Основной публичный [Releases API](https://api.github.com/repos/edwardgushchin/AI-Taskboard/releases?per_page=100&page=1) вернул HTTP 200 и `[]` без заголовка Authorization. Реальная `checkForUpdates('0.1.0')` вернула `status: empty`, `latest: null` и ссылку на основной репозиторий. Выпуски и исходники не публиковались.

## Критерии и результаты

| Критерий | Подтверждение |
| --- | --- |
| Действующий источник — основной репозиторий | Константа в `src/desktop/updates.ts`; явные ожидания репозитория и URL в `tests/updates.test.ts`; поиск `AI-Taskboard-releases` в `src`, `scripts`, `tests`, `docs` не дал совпадений. Цепочка renderer → preload → `app:checkUpdates` → `checkForUpdates` сохранена. |
| Анонимный доступ и отсутствие выпусков | [source-live.json](source-live.json): запрос через настоящую службу, проверка отсутствия Authorization, HTTP 200, тело `[]`. [updates-ipc-live.json](updates-ipc-live.json): реальный запрос через preload/main в изолированном профиле Electron, результат `empty`. |
| Успешные и ошибочные сценарии | 6 тестов службы, проверка IPC, 50 проверок Chromium — пройдены; условия перечислены ниже. |
| Документация, ожидания и свежие материалы | Обновлены `docs/design.md`, обе проверки Electron и ожидания службы. Настоящий отчёт добавлен отдельно; исторические отчёты не изменены. |

## Проверенные условия

- Служба: пустой список; текущая и более старая версии; метаданные сборки; числовое сравнение; стабильная установка с prerelease, черновиками и неверными тегами; предварительная установка с более новым/старым prerelease и переходом к стабильной версии; выбор из нескольких страниц. HTTP 403/404/429/500, неверный JSON и структура ответа, неверная текущая версия, сеть и тайм-аут; успешный повтор после ошибок.
- IPC: живая пустая выдача, версия из `app.getVersion()`, новая/текущая/prerelease версия, сетевая ошибка `UPDATE_CHECK_FAILED` и успешный повтор.
- Интерфейс: русский/английский × светлая/тёмная тема, окно 360 × 700. В каждом сочетании проверены пустая выдача, ошибки сети/API, повтор с новой версией, открытие URL основного репозитория, prerelease, текущая версия, блокировка повторного запроса при загрузке, устаревший ответ после смены панели и возврат фокуса. Всего 50 проверок.
- TypeScript и `git diff --check` — пройдены. Временные профили автоматически удалены `electronCheck`; отсутствие оставшихся профилей и процессов проверено после завершения.

## Ограничения

Реальный источник пока пуст: версии и ошибки воспроизведены тестовыми ответами. Установщик не собирался и не публиковался. Первый запуск Electron в песочнице завершился с кодом `2147483651`; повтор вне песочницы прошёл. Веб-инструмент не открыл API; анонимный доступ подтверждён прямым запросом Node и реальным Electron IPC.

```powershell

```

```powershell

```
