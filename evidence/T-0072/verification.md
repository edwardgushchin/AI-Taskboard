# Проверка T-0072

Исправлен возврат событий из `runBoardRequest`: обычное завершение, прерывание и частичная ошибка теперь применяют `managerChatItems` для полосы `chat`. Живые уведомления и чтение истории уже использовали эту функцию. Исходные события сохраняются целиком для «Хода работы». CSS и продуктовый renderer не менялись.

База: `461319f04361f799ec3ab682c72c071b507101e8`, Windows, Node `24.14.0`, Electron `45.2.3`. Все проверки выполнены с продуктовым diff этой сдачи; последующие изменения касались только UI-фикстуры и этого отчёта.

| Критерий | Условия и результат |
| --- | --- |
| 1. Нет служебных вставок | Регрессия `dialogue results filter coordination…` вызывает production IPC-handler: `manager_inbox`, `task_wait`, `task_message`, три роли, завершение / прерывание / ошибка после доставки. Служебных `messages`, `messagesOnly` и текста результата в ответе нет. UI использует production `managerChatItems`; MutationObserver следит за добавленными узлами, включая удалённые до отрисовки, при повторных потоковых обновлениях и завершении: 0 утечек. |
| 2. Сохранность | После трёх запусков чтение сохранённого work возвращает 9 событий и 9 сообщений; chat не содержит служебного текста. Chromium показывает 3 направления в live work, затем те же 3 в saved work без дублей. Чтение с диска не зависит от процесса провайдера. |
| 3. Изоляция и навигация | Chromium переключает «Диалог/Ход работы» и обратно, затем меняет проект с незавершённым чтением work: поздний ответ не попадает в новый composer. Тесты истории проверяют порядок steering и страницы из 22 запусков; отдельная production UI-проверка проверяет фоновую вкладку, два проекта, второе окно, unread и переход к старой истории провайдера. Код viewport, пагинации и учёта прочитанного не менялся. |
| 4. Публичные сообщения | В regression IPC и Chromium сохранён публичный итог менеджера. Профильные тесты сохраняют пользовательские сообщения и steering. `check-status-notices.mjs` проверяет настоящие UI/CLI-переходы, уведомления при закрытом диалоге, 3 непрочитанных сообщения, второй проект без чужих уведомлений и историю во втором окне. |
