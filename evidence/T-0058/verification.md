# Проверка T-0058

Среда: Windows x64, Node.js 24.14.0, Electron 45.2.3. База: `341299a5f5f03eb3302358cd8b38a52e2a80e50f`, сданные изменения T-0058.

## Критерии

- Пользователь может изменить положение вкладки: обработчики dragstart/dragover/drop в `renderer.js` вызывают `reorderTab` через preload. IPC меняет массив вкладок только окна отправителя. Проверены перенос фоновой вкладки вверх, активной вниз, вставка перед и после, перенос на себя, отмена, недоступная папка, неизвестные пути и внешний drop. Проверены Alt+↑ и Alt+↓.
- Вкладки отображаются в выбранном порядке: после каждого переноса проверены DOM, порядок main process и сохранение активного проекта. Проверена запись `project-tabs.json`, затем отдельный запуск Electron восстановил новый порядок и выбранный проект. Одноимённые проекты различаются путями.

## Результаты

- TypeScript — успешно.

```powershell
npm run check
```

- Синтаксис renderer и whitespace diff — успешно.

```powershell
node --check src/desktop/renderer.js
git diff --check
```

- Unit-тест вкладок — 1/1, успешно вне песочницы. В песочнице создание junction завершилось EPERM.

```powershell
node --test tests/project-tabs.test.ts
```

- Electron — 39 проверок открытия и перестановки, 9 проверок восстановления, код выхода 0. Использованы синтетические DragEvent в настоящем renderer и штатный IPC/main process. Временные профили удалены в finally после завершения Electron.

```powershell
node scripts/check-project-tabs.mjs --reorder-only --artifacts evidence/T-0058
```

Полный запуск без `--reorder-only` остановился до сценария перестановки на существующей проверке геометрии меню: `AssertionError: File menu paints above the project tabs in dark`, `checkAppearance`. Менеджер уведомлён. Режим `--reorder-only` пропускает проверки геометрии меню и hover; остальные сценарии скрипта выполняются.

Первая проверка перестановки обнаружила гонку отложенного drop с dragend. Захват пути и отмена стандартного drop перенесены в синхронный обработчик; повторный запуск прошёл. После него продуктовый код не менялся.

Не проверены физическое перетаскивание мышью и автопрокрутка длинной полосы вкладок. Полный набор тестов репозитория не запускался. Фоновая операция проверена старым сценарием переключения/закрытия, сочетание операции с перестановкой отдельно не запускалось.
