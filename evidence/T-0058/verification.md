# Проверка T-0058

Среда: Windows x64, Node.js 24.14.0, Electron 45.2.3. Повторный проход: сдача `a2677d246c1fed6d0efa870f09367f88f56f64cc` объединена с `main` на `f7314f13a146967f36a42d86c692e9de2cfa8810`. Проверки ниже выполнены заново на объединённом содержимом. После них менялись только отчёт и скриншоты.

Конфликт `docs/design.md` разрешён с сохранением описания перестановки и принятого поведения загрузки без надписи. Автоматическое слияние main.ts, renderer.js и styles.css проверено: реализация reorderTab и обработчики переноса совпадают с одобренной сдачей; изменения main в запуске задач, Codicons и загрузке сохранены. Скрипт восстановления обновлён: проверяет `aria-busy` и отсутствие удалённого элемента `#loading`.

## Критерии

- Пользователь может изменить положение вкладки: обработчики dragstart/dragover/drop в `renderer.js` вызывают `reorderTab` через preload. IPC меняет массив вкладок только окна отправителя. Проверены перенос фоновой вкладки вверх, активной вниз, вставка перед и после, перенос на себя, отмена, недоступная папка, неизвестные пути и внешний drop. Проверены Alt+↑ и Alt+↓.
- Вкладки отображаются в выбранном порядке: после каждого переноса проверены DOM, порядок main process и сохранение активного проекта. Проверена запись `project-tabs.json`, затем отдельный запуск Electron восстановил новый порядок и выбранный проект. Одноимённые проекты различаются путями.

```powershell

```

- Electron — 40 проверок открытия и перестановки, 9 проверок восстановления, код выхода 0. Дополнительно проверено, что перестановка при фоновой операции не прерывает её и не меняет выбранный проект. Использованы синтетические DragEvent в настоящем renderer и штатный IPC/main process. Временный профиль удалён в finally после завершения Electron; отсутствие каталога проверено.

```powershell
node scripts/check-project-tabs.mjs --reorder-only --artifacts evidence/T-0058
```

В прошлом проходе полный запуск без `--reorder-only` остановился до сценария перестановки на проверке геометрии меню: `AssertionError: File menu paints above the project tabs in dark`, `checkAppearance`. На объединённой версии полный режим не запускался. Режим `--reorder-only` пропускает проверки геометрии меню и hover; остальные сценарии скрипта выполняются.

Совместимость с изменениями запуска и управления чатом из main — 7/7 тестов, код выхода 0.

```powershell
node --test tests/codex-run.test.ts tests/codex-chat-control.test.ts
```

Дополнительная проверка Codicons — код выхода 1, `spawnSync electron.exe ETIMEDOUT` после лимита 60000 мс. Последний этап: `Checking manager Stop: light/ru`. Сообщено менеджеру; отдельного процесса check-icons после выхода не осталось. Это ограничение проверки, причина тайм-аута не установлена.

```powershell
node scripts/check-icons.mjs
```

Первая проверка перестановки обнаружила гонку отложенного drop с dragend. Захват пути и отмена стандартного drop перенесены в синхронный обработчик; повторный запуск прошёл. После него продуктовый код не менялся.

Не проверены физическое перетаскивание мышью и автопрокрутка длинной полосы вкладок. Полный набор тестов репозитория не запускался.
