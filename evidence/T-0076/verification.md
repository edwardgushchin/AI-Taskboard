# Проверка T-0076

Превью ограничено 180 px вместе с рамкой. Изменены только стиль обложки и обработчик загрузки: исходная ширина задаётся до снятия hidden, CSS уменьшает широкие картинки и обрезает высокие через object-fit: cover с object-position: top. Маленькие изображения не увеличиваются. Оригинал и просмотрщик не менялись.

## Ограничения и диагностика

Первый запуск Electron в песочнице завершился кодом 2147483651; проверки выполнены с разрешённым запуском Electron. Ранние ошибки теста исправлены: ожидаемая ширина учитывает padding; повторная функция не объявляет const в глобальном контексте; системная тема задаётся через nativeTheme; первая задача в проверке колонки закреплена датой сортировки; Enter отправляется с событием char, результат проверяется через taskInSheet. Производственный код после полного прогона не менялся: последующие правки затрагивали только целевой тест и документацию.

check-chat-attachments.mjs не пройден: запуск без обязательного --task завершился AssertionError и тайм-аутом; запуск с --project и --task T-0076 отклонён самим тестом, поскольку он требует отдельного события attach, а вложение карточки добавлено при создании. Проверка оригинала выполнена через существующий просмотрщик в --covers-only. Отдельного теста скачивания оригинала не было; код хранения, выдачи и скачивания не изменён.

Временные профили electronCheck удалены штатным finally; проверка TEMP не обнаружила каталогов ai-taskboard-*. Диагностика неудачных попыток сохранена здесь текстом; промежуточные PNG удалены.
