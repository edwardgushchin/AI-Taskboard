# Security policy / Политика безопасности

[English](#english) · [Русский](#русский)

## English

Report vulnerabilities privately by email to [eduardgushchin@yandex.ru](mailto:eduardgushchin@yandex.ru). Include the affected release tag or commit, your operating system and a short description of the impact. Remove credentials and private project data from any attachments.

Keep vulnerability details out of public issues and pull requests.

## Русский

Сообщайте об уязвимостях по электронной почте на адрес [eduardgushchin@yandex.ru](mailto:eduardgushchin@yandex.ru). Укажите тег затронутого выпуска или коммит, операционную систему и кратко опишите возможные последствия. Удалите учётные данные и частные данные проекта из вложений.

Не публикуйте сведения об уязвимостях в issues и pull request.
