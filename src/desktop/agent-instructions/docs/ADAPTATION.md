The adaptation retains the thin index, init/update/audit modes, Diátaxis, content routing, innermost placement, single ownership, deterministic and semantic drift checks, P0/P1/P2 priorities, repeatability and explicit outcomes.

The three routing/style rules are combined into one file. README design is task-scoped rather than forced marketing scaffolding. Provider-specific memory files, imports, hooks, invocation syntax, confidence gating, personal configuration and independent commits are removed. Hidden proposed/removed-rule ledgers become ordinary card history and submission evidence. The board owns permissions, profiles, lifecycle and review. Detailed rules are loaded on demand through ordinary read-only file access; only a short role rule enters each session.
