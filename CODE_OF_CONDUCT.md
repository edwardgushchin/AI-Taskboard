# Code of conduct / Правила поведения

[English](#english) · [Русский](#русский)

## English

Treat people with respect in this repository's issues, pull requests and other project discussions. Give feedback on the work, explain disagreements and give others room to participate. Harassment, threats, discriminatory remarks, personal attacks and sharing someone's private information without consent are unacceptable.

Use GitHub's [Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) controls to report abusive content. If the report control is unavailable, use the GitHub Support contact form linked from that guide. Include links to the affected discussion. Keep private information out of public threads. Maintainers may remove harmful content, limit participation or block accounts depending on the severity and whether the behavior recurs.

## Русский

Уважайте участников в issues, pull request и других обсуждениях проекта. Обсуждайте работу, объясняйте, с чем вы не согласны, и давайте другим высказаться. Недопустимы преследование, угрозы, дискриминационные высказывания, личные нападки и публикация чужих частных данных без согласия.

Чтобы сообщить о нарушении, воспользуйтесь [жалобой на содержимое в GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Если кнопка жалобы недоступна, воспользуйтесь формой обращения в GitHub Support по ссылке из инструкции. Приложите ссылки на обсуждение. Не публикуйте частные сведения в открытой переписке. Сопровождающие проекта могут удалить вредоносные сообщения, ограничить участие или заблокировать аккаунт с учётом тяжести и повторяемости нарушения.
