## Технические детали

Первая попытка применения получила `EPERM` при создании временного файла журнала в домашней доске; данные не изменились. Через разрешённое выполнение вне песочницы запись стала доступна. Попытка передать манифест через преобразования JSON PowerShell была отклонена из-за изменённого представления дат. Node прочитал исходный JSON без преобразований; dry-run и применение успешно выполнились через публичный CLI. Защиты не отключались, исходный манифест не менялся.

Для операции передают объект `{ "manifest": <исходный манифест> }` через stdin или UTF-8 input-file. Для применения добавляют `"apply": true`. Даты нужно сохранять как исходные строки. Повторное применение исходного манифеста после удаления ожидаемо отклоняется.

```powershell
node --disable-warning=ExperimentalWarning src/cli/main.ts --project 'C:\Users\eduar' --json recover-test-data --input-file '<UTF-8 JSON с manifest>'
```
