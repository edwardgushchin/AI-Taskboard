# T-0082: статистика токенов проекта

Статистика доступна из меню шестерёнки для активного проекта. Итог, модели и роли включают архивные карточки и отдельные отчёты менеджера. Неизвестные счётчики показаны как отсутствие данных, неполнота отмечена отдельно. Обновление происходит каждые пять секунд, пока экран открыт.

Проверен продуктовый diff на `0eff031e7ffb674f36b5cd1f98973f3d68bad43a`, содержащем `main` `587ada0455f7e59ef1cd19c373539a37c593ca98` (включая T-0081, T-0073 и T-0084). Последующие изменения расширяют только проверки и сохраняют доказательства; продуктовый код не менялся. Тесты учёта и TypeScript повторены после расширения проверок.

## Ограничения и уборка

Первый проход ошибочно создал три тестовые карточки в родительской доске C:\Users\eduar. Адресный откат и исправление выбора корня выполнены отдельной T-0084; менеджер подтвердил удаление 360 тестовых токенов, сохранность manager-usage и nextId=17. Доказательства: [отчёт T-0084](../T-0084/report.md), [before.json](../T-0084/before.json), [after.json](../T-0084/after.json). Во втором проходе чужие данные не менялись.

IPC-фикстура устанавливает GIT_CEILING_DIRECTORIES и проверяет точный канонический project после init каждой из двух временных досок до записи карточек/usage. Временные профили и доски удаляются electronCheck в finally; после проверок в TEMP не осталось ai-taskboard-statistics*. Electron требовал расширенного доступа: ограниченный запуск в первом проходе завершился 2147483651. Слияние Git завершилось успешно, несмотря на предупреждение packed-refs.lock Permission denied; HEAD и ancestry main проверены после операции.
