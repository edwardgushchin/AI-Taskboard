## Помочь проекту

- [Как сообщить об ошибке, предложить улучшение или отправить pull request](../CONTRIBUTING.md#русский).

Отчёты отдельных проверок хранятся во вложениях и материалах локальной доски `.tasks`, вне публичного дерева исходников. В отчётах указываются команды воспроизведения и версии среды.
