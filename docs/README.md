# Документация AI Taskboard

AI Taskboard хранит задачи проекта локально и связывает работу агента с проверкой результата.

## Начать работу

- [Первая задача](tutorials/first-task.md): от открытия доски до приёмки.
- [Установка и настройка](how-to/setup.md): приложение, Codex, Git и параметры доски.
- [Разработка и проверки](how-to/development.md): запуск из исходников и сборка.

- [Состояния, настройки и CLI](reference/board.md).

Отчёты отдельных проверок хранятся во вложениях и материалах локальной доски `.tasks`, вне публичного дерева исходников. В отчётах указываются команды воспроизведения и версии среды.
