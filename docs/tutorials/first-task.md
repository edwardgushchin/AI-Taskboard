# Первая задача

Подготовьте приложение, Codex и Git по [инструкции установки](../how-to/setup.md).

1. Откройте AI Taskboard. Выберите папку проекта и создайте доску, если её ещё нет.
2. В чате менеджера опишите небольшое изменение и ожидаемый результат.
3. Откройте созданный черновик. Проверьте постановку и критерии, затем утвердите задачу.
4. Запустите исполнителя из карточки. Для Git-задачи выберите целевую ветку. Доска подготовит отдельный worktree.
5. Дождитесь сдачи. Карточка перейдёт на проверку; в ней появятся итог и результаты проверок.
6. В режиме human изучите изменения, проверки и сведения об обновлении документации. Верните задачу с конкретными замечаниями либо примите результат.

После успешной приёмки задача завершена. В Git-проекте результат интегрирован в целевую ветку.
Другие режимы описаны в [справочнике доски](../reference/board.md#проверка).
