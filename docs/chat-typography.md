# Шрифт ответов агента

Для T-0043 проверены файлы установленного на Windows Codex 26.1106.6628.0
(версия приложения в `package.json` — 26.1106.51428), 12 ноября 2026 года.
Источник — `app/resources/app.asar` в пакете
`OpenAI.Codex_26.1106.6628.0_x64__2p2nqsd0c76g0`.

В `webview/assets/async/9ec44337a842.css` определена цепочка:

```css
--font-sans-default: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
--font-sans: var(--font-ui-family, var(--font-sans-default));
--font-content: var(--codex-content-font-family, var(--font-sans));
```

Текст ответа использует `font-content`; например, это видно в
`webview/assets/async/08264d052736.css`. Установка пользовательского семейства
в `--codex-content-font-family` реализована в
`webview/assets/async/739301.37a39f26d6.js`. В проверенных настройках Codex
переопределения шрифтов отсутствуют, размер контента — 15 px.
[Официальная справка](https://learn.chatgpt.com/docs/reference/settings#appearance)
подтверждает возможность настройки шрифтов, но не называет семейство;
семейство установлено по файлам приложения. SHA-256 основного CSS:
`2cb9b48f61a47328f5fede2c368cee0ab6efdaedffdb93ec17532983abb0375d`.

На Windows этот стек выбирает **Segoe UI**, включая кириллицу. Наличие файлов
`OpenAISans-*.woff2` в том же пакете само по себе не означает, что ими
набраны ответы Codex: по умолчанию `font-content` ссылается на системный стек.

AI Taskboard уже наследовал Segoe UI от корня интерфейса, но с размером 14 px.
Теперь у текста агента явно задан стек Codex и размер 15 px. Правило охватывает
сохранённые ответы, промежуточные сообщения и итог запуска, а также поступающие
сообщения. Размеры заголовков Markdown остаются относительными; код сохраняет
моноширинное семейство. Системный шрифт не требует загрузки из сети или копирования
файлов Codex в приложение.

Проверка: `node scripts/check-chat-font.mjs` запускает настоящее приложение
Electron из рабочей копии с отдельным профилем и тестовой перепиской в памяти.
Стили загружаются штатным `index.html` с его CSP. Через Chromium DevTools
`CSS.getPlatformFontsForNode` проверяется фактически отрисованный шрифт отдельно
для латиницы и кириллицы, включая Ё/ё, обычное и жирное начертания. Также
проверяются история, текущие сообщения, повторное открытие и моноширинный код.
JSON с результатами и снимки светлой и тёмной тем сохраняются в
`.dev-diary/chat-font-check/`. Данные доски и Codex не меняются.

На Windows с Electron 45.2.3 прошли 16 проверок реальных шрифтов. Для русского
абзаца Chromium сообщил `SegoeUI`, 67 глифов, `isCustomFont: false`; для жирного
текста — `SegoeUI-Bold`, для курсива — `SegoeUI-Italic`. Для блока кода подтверждён
`Consolas`, 12 px. Снимки обеих тем просмотрены. Проверка использует тестовую
переписку; пользовательская оценка удобства чтения остаётся частью приёмки.
