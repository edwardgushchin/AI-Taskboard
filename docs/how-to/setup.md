# Установить и настроить приложение

## Готовая сборка

Откройте [GitHub Releases](https://github.com/edwardgushchin/AI-Taskboard/releases) и разверните **Assets** нужного выпуска. Публичный alpha-выпуск доступен для x64 и ARM64. Сверьте SHA-256 пакета с файлом `SHA256SUMS` из того же выпуска. Команды есть в описании выпуска.

- Windows. Откройте «Параметры» → «Система» → «О системе» и проверьте тип системы. Для процессора x64 скачайте `ai-taskboard-<версия>-windows-x64.exe`, для ARM64 — `ai-taskboard-<версия>-windows-arm64.exe`. Установщик alpha-выпуска не подписан.
- Linux. Установите `.deb` в Debian или Ubuntu либо `.rpm` в дистрибутиве с поддержкой RPM.
- macOS. Распакуйте `.zip` и откройте приложение. У alpha-сборки подпись ad hoc, без нотариального заверения Apple.

В пакет входят приложение, автономный CLI и его среда Node.js. Для Git-задач установите Git 2.38 или новее. Чтобы запустить приложение из исходников, следуйте [руководству разработчика](development.md).

Для запуска агентов установите Codex. В настройках AI Taskboard проверьте обнаруженный исполняемый файл Codex. При необходимости выберите его вручную.

## Вход в Codex

Выбор ключа в настройках AI Taskboard описан для текущих исходников. Для опубликованного `v0.1.0-alpha` войдите в Codex до запуска агентов.

Если вы уже вошли в Codex через ChatGPT или API-ключ, оставьте способ входа «Профиль Codex». Настройки покажут, какой вход распознал App Server. Чтобы войти через ChatGPT в этот профиль, выполните:

```text
codex login
```

Чтобы задать API-ключ только для AI Taskboard, откройте настройки Codex, выберите «Ключ OpenAI API», введите ключ и нажмите «Проверить и применить». Приложение проверит доступ к списку моделей OpenAI. Если проверка не прошла, текущий способ входа останется активным.

Codex сохраняет ключ для отдельного профиля AI Taskboard через системное хранилище ключей. Чтобы снова использовать сохранённый ключ, оставьте поле пустым и нажмите «Применить способ входа». Приложение подтвердит выбор профиля. Для сетевой проверки введите ключ.

Чтобы вернуться к обычному профилю Codex, выберите «Профиль Codex» и нажмите «Применить способ входа». Выбор действует для новых подключений всех ролей и сохраняется после перезапуска. Чаты хранятся в профиле, в котором были созданы. Чтобы продолжить старый чат, вернитесь к его профилю.

Вызовы API оплачиваются отдельно через [OpenAI Platform](https://platform.openai.com/usage). Панель «Лимиты» показывает окна квоты Codex при подключении через ChatGPT. Если подключение не предоставляет окна, панель оставляет раздел без строк окон и пояснения об их недоступности.

## Доска

Откройте папку проекта или создайте в ней доску. Данные хранятся в `.tasks`.
Для Git worktree используется общая доска репозитория.
Настройки моделей, уровней рассуждения, лимитов агентов и режима проверки относятся к доске.
Настройки внешнего вида приложения действуют во всех окнах.
Смысл режимов описан в [справочнике](../reference/board.md).

## Резервные копии

Откройте доску и выберите «Резервные копии» в меню настроек. Нажмите «Создать копию сейчас» или включите «Копировать эту доску раз в час». Пока приложение работает, оно создаёт отдельные почасовые снимки и удаляет их через 24 часа после создания. Папку хранения приложение определяет само и показывает в настройках вместе со временем последней успешной копии и причиной последнего сбоя.

Снимок включает карточки, архив, настройки доски, журнал, локальную историю и содержимое загруженных вложений. Для прикреплённых по ссылке файлов сохраняются ссылки. Доступ к таким файлам зависит от исходных путей. История провайдера, файлы проекта, Git и незакоммиченные изменения в рабочих копиях хранятся отдельно.

Если приложение не смогло записать настройки почасового копирования, оно покажет причину и время последней успешной копии. Когда файл настроек снова доступен для записи, приложение повторит пропущенную попытку.

Выберите снимок в настройках и нажмите «Восстановить из копии». Если исходная папка `.tasks` недоступна, откройте тот же список через «Восстановить из копии» на экране приветствия. Приложение проверит целостность снимка, предложит выбрать родительскую папку и покажет исходный путь доски, дату и новый путь перед подтверждением. В новую папку откроется доска с выключенным авторежимом. Исходная доска и снимок сохраняются. Если путь назначения уже занят, выберите другую родительскую папку.

В восстановленной доске расписания приостановлены, а ожидавшие автоматического запуска обсуждения и продолжения требуют явного действия владельца. Очередь архивирования чатов Codex сбрасывается, ссылки на чаты сохраняются. Перед запуском карточки проверьте её рабочую папку. Она может ссылаться на каталог исходного проекта.

## Оформление

В настройках приложения откройте «Оформление» и выберите «Светлая», «Тёмная» или «Как в системе». Выбор сохраняется после перезапуска. Системный режим следует за оформлением ОС, включая смену по расписанию, пока приложение открыто. Явно выбранная тема от смены оформления ОС не зависит.

При смене палитры приложение делает короткий плавный переход. Если в ОС включено уменьшение движения, палитра меняется сразу. При обновлении старые пресеты переходят на стандартную тему той же светлоты; системный режим и остальные настройки сохраняются.

## Обновление

Приложение проверяет обновления через несколько секунд после запуска, затем раз в час, пока оно открыто. Когда доступна новая версия для вашего канала, в правом нижнем углу шестерёнки появляется круг со стрелкой вниз. Откройте меню шестерёнки и выберите «Обновить», чтобы увидеть версию, список изменений и ссылку на выпуск. Если новой версии нет, в меню доступно «Проверить наличие обновлений».

В установленном Windows-клиенте NSIS нажмите «Обновить». Фоновая проверка продолжится, а диалог сохранит выбранную версию до завершения обновления или закрытия подтверждения. После загрузки и проверки пакета выберите «Обновить и перезапустить» или «Позже». При ошибке можно повторить загрузку. Если Windows удерживает скачанный установщик, приложение покажет причину и продолжит работу. Освободите файл и снова нажмите «Позже» или повторите выход из приложения. В распакованном клиенте, сборке из исходников, Linux и macOS откройте страницу выпуска и установите подходящий пакет вручную.
В диалоге менеджера можно попросить «Проверь обновления AI Taskboard», затем явно указать «Установи AI Taskboard <найденная версия>». Менеджер сообщает текущую и найденную версии. Установленный Windows-клиент NSIS поддерживает загрузку, проверку SHA-256 по манифесту официального выпуска и установку с перезапуском. Подтвердите версию в диалоге приложения. Профиль и открытые доски сохраняются. Если идёт другая работа, дождитесь её завершения и повторите команду. Отмена или ошибка проверки пакета оставляет текущую версию работающей.

Для Linux, macOS, запуска из исходников и распакованного Windows-приложения менеджер возвращает ссылку на выпуск. Скачайте пакет своей ОС и архитектуры и установите его вручную. Без команды пользователя пакеты не загружаются.
Данные досок остаются в папках проектов.
