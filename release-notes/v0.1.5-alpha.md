v0.1.4-alpha

- The daily Codex budget updates during active turns and excludes cached input. Set a reset time per board or reset the board counter from Limits. Executors, reviews, and background turns wait for budget after the threshold is reached.
- Card dialogues save messages and attachments while either limit is exhausted and answer them in order when both limits allow it. An active reply to the owner's message can finish. If Codex interrupts it for quota, the board resumes it in the same session and preserves edits already made.
- Sent card messages appear immediately, and the composer keeps the draft if saving fails. Work history shows execution and review in one timeline, preserves the reading position, and wraps long messages.
- The manager dialogue preserves its reading position when you switch boards or return to the app. Interrupted replies show their status and can be recovered from saved provider history or checked in a read-only session.
- Long Codex goals are stored in Markdown. Full-text replacements preserve whitespace and code blocks, and interrupted goal changes are reconciled before work continues.
- Chat links can open cards on other open or recent boards. Use the board name and card number, and enclose the full link in backticks when the board name starts with a card number.
- New agent boards start with Codex gpt-6.2-sol at medium reasoning, two executor slots, one review slot, and no daily budget. Existing boards keep their settings.
- Import existing AGENTS.md instructions as project rules. You can edit, reorder, and toggle rules independently while keeping their nested content.
- On Windows, Codex card executors can request scoped access to the board's Computer Use and Browser Use test surfaces. The local test site and isolated Chrome test window have separate surfaces.
- AI Taskboard retries confirmed Codex routing discovery failures, resolves linked manager waits when an executor replies, and reuses stable review context.
- The image viewer has a context menu. The manager chat header and queue align their controls, and the board activity scrollbar sits at the panel edge.
- German, Spanish, French, Italian, Japanese, Dutch, Polish, and Portuguese now cover more of the interface, including recovery actions and Codex status.
- Updates can proceed when a board has idle runtime records. Active work still guards against restarting for an update.
