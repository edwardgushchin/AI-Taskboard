v0.1.2-alpha

- With Auto mode and iterative execution enabled, the manager can wake on task and board events or on an interval configured by an explicit instruction in the goal. You can also change the active goal from manager dialogue. Requests that leave the replacement unclear ask for clarification.
- Auto mode starts eligible work in release milestone order. Recurring cards follow their own schedules and stay outside release gating. A dependent card can return to the queue when its prerequisite is accepted.
- Scheduled cards appear first within each column and show a clock beside their schedule. Open cards show subtasks before acceptance criteria, and cancelled cards hide the waiting-for-answer badge.
- Manager messages sent from either chat tab go to Dialogue. The manager chat supports clipboard editing, and selected text from manager and task chats can be added to drafts with an optional comment. Markdown links with source line numbers open the source viewer at the linked line.
- Manager-created cards require topic tags. Specialist history preserves command outcomes even when the final activity snapshot arrives late.
- Codex retries transient failures when reading limits and when checking write access before launch. If a turn may already have been sent, the board checks its outcome before another launch. When it can no longer establish that outcome, it blocks the card for review.
- About shows the package version and available build details. A package built with local changes identifies its base commit and marks the build as modified.
- In Windows Electron long-session testing on two boards with 771 cards and 3,483 history files each, the longest manager dialogue opening fell from 84.44 s to 632 ms and p95 fell from 434 to 358 ms. Status rendering and board switching still showed occasional spikes. These results apply to the tested workload.
- In a separate Windows Electron test, the median time to a visible message on reopening an already loaded manager chat fell from 402–634 ms to 75–83 ms across four scenarios. In the scrolling test with background updates on a large board, frame intervals above 50 ms fell from 10 to 7.
- In queued Worklog write tests, the median of series p95 values fell from 3.56 to 1.63 s on a 91 MiB journal and from 4.16 to 1.71 s on a 182 MiB journal. Each series queued 12 writes.
